# Models, Effort, and Permissions

Scribe 的 Agent Chat、Quick Ask 和 Quick Command 使用同一套模型连接。你可以使用云端供应商、兼容服务或本机模型；模型服务决定访问权限、费用和实际能力。

模型连接配置保留在插件设置中，密钥单独加密保存在当前库内。旧系统钥匙串中的密钥不会自动导入，升级后需要重新填写；详情见[密钥保存方式](llm-providers.md#where-keys-are-stored)。

## Where models come from

在 **Settings → Scribe → 模型** 添加供应商，按需要填写密钥及地址，然后选择或手动输入模型。目录中没有能力标签的手动模型仍可加入 Agent Chat。

Agent Chat 不再使用外部代理的账号、模型列表或订阅额度。Anthropic 和其他供应商一样，通过模型与供应商设置接入。

## Available models and initial choices

- **模型** 中配置保存的聊天模型直接供 Agent Chat、Quick Ask 和 Quick Command 使用，不再有独立模型开关或代理总开关。
- 新聊天沿用最近一次成功选择的模型、推理强度和权限模式。首次使用时，采用配置顺序中第一个凭据可用的模型，权限为 **自动模式**。
- Quick Ask、Quick Command 及选择 **默认模型** 的编辑器指令，使用第一个可用的已配置模型。单条指令指定的模型和弹窗临时选择继续生效。
- 已有聊天保留自己的选择；旧设置中保存的模型和权限选择继续作为之后新聊天的初值。

没有已保存密钥或密钥文件不可读取的模型不会被自动选中。已保存但尚未用主密码解锁的模型仍可以选择；首次发送时会先请求解锁。取消解锁会保留输入内容，不发送请求。查看模型列表本身不会解密密钥。

供应商可能仍因网络、额度或访问权限而拒绝请求；这些需要按实际提示处理。

## Choose a model while chatting

输入框旁的模型和推理强度选择应用于当前聊天，成功切换后也会成为下一聊天的初值。模型支持时才显示相应强度；未明确指定时沿用已保存的模型配置或供应商默认值。 **Default** 保留模型原来的思考设置；**Off** 是明确关闭，只有模型报告支持时才提供。切换后从下一次请求生效，重新选择 **Default** 即恢复原来的默认行为。

更高推理强度可能增加耗时和用量。模型可以提出工具调用；Scribe 根据权限决定是否允许并执行工具。端点拒绝工具或无法继续时，会保留模型、连接方式和失败阶段的错误信息。

## Model, effort, and permissions

| 使用位置        | 可调整的内容                                           |
| --------------- | ------------------------------------------------------ |
| **Agent Chat**  | 模型、支持的推理强度、Default / Plan / Auto 权限模式。 |
| **Quick tools** | 已配置的聊天模型；弹窗选择仅对当前弹窗生效。           |

**Default** 下，编辑和执行命令通常需要批准。保持 **Plan** 时，编辑和命令执行会被阻止；批准计划会让当前聊天切回 **Default**，你也可以手动切换模式。**Auto** 通常自动允许资料库内的普通笔记和绘图编辑，但不自动放行资料库配置目录中的编辑或系统命令。编辑和命令可在当前聊天中保存对相同操作的允许或拒绝；已保存的决定先于 Auto 规则生效，所以权限卡不一定每次出现。具体选项以卡片显示为准。

在聊天中手动切换权限模式，也会更新之后打开聊天时使用的默认模式；批准计划后的自动切换只改变当前聊天，不更改已保存的默认值。
