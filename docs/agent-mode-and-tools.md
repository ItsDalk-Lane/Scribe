# Agent Chat

Agent Chat 是 Scribe 的桌面聊天工作区。Scribe 直接在 Obsidian 内运行自己的代理，沿用你已配置的模型、密钥和连接地址。开始聊天不需要安装或登录外部代理程序。

Quick Ask、Quick Command 继续用于编辑器旁的简短提问和改写，也保留移动端入口。

## Set up Scribe

1. 打开 **Settings → Scribe → 快捷操作 → 模型**，添加供应商或本地模型，并填写它需要的连接信息。
2. 在 **代理 → Scribe** 中启用要用于聊天的模型，选择默认模型、推理强度和权限模式。
3. 点击 Agent Chat 图标，或运行 **Open Scribe Agent Chat window**，输入任务。

没有模型时，聊天会引导你回到模型设置。已有供应商、密钥和自定义地址继续使用；Agent Chat 与快捷工具可以分别启用模型。Anthropic 也通过同一套自备模型设置接入。

## Models, effort, and permissions

输入框旁的模型选择只影响当前聊天。推理强度按模型支持的选项显示；更改后在下一次请求中使用。具体支持情况和费用由你的模型服务决定。

| 模式        | 行为                                                                                   |
| ----------- | -------------------------------------------------------------------------------------- |
| **Default** | 可以读取和搜索笔记；写入笔记、修改绘图和执行系统命令前请求批准。                       |
| **Plan**    | 先提交计划供你审阅，等待批准后再执行需要计划授权的操作。可以拒绝计划或附反馈退回修改。 |
| **Auto**    | 自动允许资料库内的笔记及绘图编辑；系统命令仍请求批准。                                 |

权限卡显示具体操作、发起者、命令或文件信息。选择允许或拒绝只处理相应请求；可持续使用的选项以卡片实际提供的范围为准。**Stop** 取消当前回复及其尚未回答的请求。

提问卡支持多题导航、选项和自行填写。提交后，答案回到提出这组问题的工具；取消会结束这次等待。

笔记工具限定在当前资料库内。经批准的系统命令使用你的电脑权限，可能访问资料库以外的文件或服务。

## Context and history

每条聊天独立保存草稿、附件、排队消息、项目归属和任务结果。切换聊天不会把另一条聊天的问题或草稿带进来。

- 通过原输入区添加笔记、编辑器选区、网页、图片和其他支持的附件；输入 `@` 或 `[[` 选择笔记。
- 项目保留自己的说明、上下文和聊天列表。共享技能可以复用，项目技能只在对应项目的聊天中出现。
- **Recent chats** 和 **Chat history** 保留查找、重命名、分叉、保存为笔记、复制链接、书签和删除入口。
- 消息下面可以复制正文、在编辑器光标处插入或替换，以及从该处建立新的聊天分支。
- 新的原生会话使用独立的记录。重启后恢复历史只重建显示，不会重跑终端、重新写文件或重复批准。旧外部代理的会话不导入、不接续，原有笔记和历史文件保留。

回复会逐步显示 Markdown、代码块和供应商实际提供的可展示思考内容。向上滚动时不会强制跳回最新位置；使用原来的向下按钮可继续跟随。

上下文环显示模型实际返回的用量；没有数据时保持缺数状态。这里不再显示外部代理账户的订阅额度。

### Fork a conversation

在一条已完成的回复下选择 **Fork conversation**，可从该位置建立独立的新聊天。原来的聊天和任务保留。保存的工具活动作为历史显示，分叉不会复制执行它们。

### Compact a long chat

在输入开头选择 **/compact**，可让当前模型总结较长的聊天。Scribe 也会在接近上下文上限时尝试压缩。聊天中分别显示进行、完成、失败、取消或无需压缩；完成后可继续追问。

### When a reply stops early

停止、拒答、输出长度上限、每轮步数上限和连接错误会分别显示。出错的回复不会被当成成功；可以从原有入口重试，或发送新消息继续。

## While the agent works

### Send a message

可以在代理工作时继续输入。排队消息在代理下一步读取后才进入对话；**Withdraw queued message** 将尚未读取的内容及附件放回输入框。**Send now** 会停止当前回复，再立即处理等待消息。

### Background subagents and commands

Scribe 可以委派真实子代理，也能执行前台或后台系统命令。每个任务有自己的身份、输出和状态。子代理在独立上下文中工作，将结果交回父聊天，并使用对应的权限请求。

打开输入区上方的任务入口，可以查看子代理详情、后台命令的真实输出尾部、截断提示及成功、失败或停止状态。关闭详情仅关闭视图。**Stop task** 停止指定任务；其他任务继续运行。主回复结束后，后台任务仍可单独保持运行。

## Review what a turn changed

工具活动保留原有的读取、搜索、编辑、命令、网页和技能卡片。展开后可查看真实参数、路径和结果，并从原入口打开笔记。

写入或编辑后，变更摘要显示实际文件数和修改前后的差异。拒绝执行的操作不会被列成已写入。绘图在已发生部分修改后失败时，也保留实际变更。

## Skills

在 **Settings → Scribe → Skills** 管理 Scribe 技能。可查看和编辑你管理的技能，调整是否允许模型调用或在 `/` 菜单中显示。技能保存和启用错误会保留具体原因。

在聊天中输入 `/` 选择允许手动调用的技能或已启用的 [Scribe 命令](custom-commands.md)。模型也可以调用已注册且允许自动调用的技能。项目技能只提供给对应项目；切换项目后，菜单和实际执行使用同一范围。

Scribe 内置 Obsidian Markdown、Bases、Canvas 等说明技能。`obsidian-cli` 技能仍需要在 Obsidian 的 **Settings → General → Command line interface** 开启命令行功能。

## Check extensions without sending a message

**Skills、Commands、Subagents** 页面使用 Scribe 实际注册的条目。**Refresh and check** 核对其状态，不发送模型消息，也不为了检查而执行任务。

命令继续使用原有的 Scribe 命令存储，可新建、编辑、启停和删除；更完整的快捷命令选项仍在 **快捷操作 → 我的命令**。子代理页显示内置委派能力及详情。

本版本不加载旧外部代理的插件市场、插件包、启动钩子或 MCP 配置，也不提供这些安装和导入入口。机器上原有的外部配置文件保留。

## Excalidraw drawings

启用支持的 Obsidian Excalidraw 插件后，Scribe 会注册原有绘图读取、图片预览和写入工具。模型可以按任务选择这些工具。

绘图仍由 Excalidraw 插件创建和保存；写入服从所选权限模式，聊天保留专用卡、打开绘图入口和实际文件差异。插件未启用或某项功能不受支持时，Scribe 显示对应原因。

## Feedback

模型可以起草 Scribe 问题报告；草稿只属于发起它的聊天。你可以审阅、编辑、取消或提交，模型起草本身不会发送报告。也可以从聊天的原菜单自行 **Report an issue**。

## Applying a settings change

已有聊天会按其当前任务状态应用配置更改，等待中的变更会显示状态。需要重新加载时，使用原来的恢复入口；历史和未发送草稿继续保留。
