## 共同数据与操作契约

会话边界位于 `src/agentMode/session/types.ts`，界面访问边界位于 `AgentChatBackend.ts`。`SessionEvent` 必须携带正确的 `sessionId`；子任务事件使用 `taskToolCallId` 归属子会话。工具首次出现用 `tool_call`，后续用同 ID 的 `tool_call_update`；`parentToolCallId` 保留父子关系。正文、思考、计划条目、计划审批、实际任务和压缩各有独立数据，不能互相替代。

真实验收时，记录请求/回合/调用/任务 ID、选中模型与协议、界面动作、完成结果及实际文件/进程变化。恢复历史仅重放事件，不重复执行。以下路径未带目录时，组件、测试及示例位于 `src/agentMode/ui/`；会话测试位于 `src/agentMode/session/`，其他位置单独标明。
